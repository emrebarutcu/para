## 説明 (≤4000)

クレジットカードの分割払い、リボ払い、ボーナス払い。「来月いくら引き落とされるんだっけ？」をなくすアプリです。

CashFollow は、カードごとの締め日と支払日から、すべての支払いがいつ・いくら引き落とされるかを自動で計算します。買ったものと支払い回数を入力するだけで、毎月の支払い予定と残高の見通しがひと目でわかります。

■ 分割払い・リボ払い・ボーナス払いをまとめて管理
・分割払い：支払い回数を選ぶだけ。毎月の支払額と残り回数を表示
・ボーナス払い：夏（8月）・冬（1月）のボーナス月の支払日に一括で。ボーナス2回払いにも対応。ボーナス月はカードごとに変更できます
・リボ払い：残高と毎月の支払額を記録すれば、払い終わる月まで支払い予定に表示
・締め日と支払日：締め日までの利用は今月の明細、それ以降は翌月の明細へ。15日締め翌月10日払い、月末締め翌月27日払いなど、どんなカードでも
・カードの利用可能額：これから支払う分を差し引いた残りの枠を表示

■ 「これ、買っても大丈夫？」
買う前に金額を入れると、どの月の支払いがいくら増えるか、月末にいくら残るかを試算します。どのカードで買えば支払いがいちばん遅くなるかもわかります。

■ お金の流れが見える
・月ごとの支払い予定（カード別・日付別）
・給料などの収入を入れると、毎月の自由に使えるお金を計算
・支払いが急に増える月、ボーナス払いの引き落とし日、カードの利用枠をお知らせ
・現金、外貨、金（ゴールド）も資産として管理
・借りたお金・貸したお金、ローンの返済も記録

■ 家族のカードもいっしょに
家族やパートナーの分もひとつのアプリで。誰がいくら使ったか、誰にいくら返してもらうかもわかります。

■ プライバシーを大切に
銀行やカード会社のIDやパスワードは一切不要です。口座連携はしません。入力したデータはあなたのアカウントだけに保存され、広告に使われることも、第三者に売られることもありません。

■ AIアシスタント
ChatGPT や Claude などのAIアシスタントとつなげば、「テレビを夏のボーナス払いで追加して」「来月の引き落としはいくら？」と話しかけるだけで記録・確認ができます。

■ iPhone と Web で同じデータ
cashfollow.app でも同じアカウントで使えます。

CashFollow Premium（サブスクリプション）では「これ、買っても大丈夫？」の試算、AIアシスタントとの連携などが使えます。料金と期間はアプリ内に表示されます。購入は Apple ID に請求され、期間終了の24時間前までに解約しない限り自動更新されます。
